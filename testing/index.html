Delivery gates

Compatibility and package shape are explicit.

CI runs modern vanilla-test suites across platforms, a fallback harness with production dependencies only on older supported Node releases, native coverage in Chrome, and a packed-artifact install check. Pages deploys only after that main run succeeds.
