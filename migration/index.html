Version 2 → 3

Modern modules. Familiar flow.

FIFO execution, automatic start, explicit this.next(), stop gates, clearing, CommonJS, classic scripts, and the stack path all remain available.

What changed

Four boundaries to inspect.

Most consumers can upgrade without rewriting task logic. Check loading, input values, subclassing, and the runtime baseline.

Modules

ESM is native; CommonJS is conditional

import Queue from 'js-queue' and require('js-queue') each resolve to their native format.

Validation

Tasks must be functions

add() and contents replacement reject invalid values before partially mutating the queue.

Classes

Use extends Queue

Methods now live on the class prototype. Replace MyQueue.prototype=new Queue inheritance.

Runtime

Node 12.22 or newer

The ESM and conditional-export baseline replaces the historical Node 1 package declaration.

Synchronous errors are now recoverable.

The error still reaches the caller, while running resets and later work stays pending.

Upgrade checklist

Verify the edges, then run.

  • Select ESM, CommonJS, or the classic browser file explicitly.
  • Ensure every value passed to add() is a function.
  • Use class Name extends Queue for custom queues.
  • Do not depend on methods being enumerable own properties.
  • Catch synchronous task errors at the execution boundary.
  • Keep every intended hand-off at this.next().
  • Run the application integration suite on Node 12.22 or newer.
